# 05 — API Specification (v1)

Base path `/api/v1`. JSON (UTF-8). OpenAPI generated by FastAPI at `/api/v1/openapi.json`, docs at `/api/docs`
(disabled in production unless `API_DOCS_ENABLED=true`). Frontend types are generated from the OpenAPI schema
(`openapi-typescript`) so contracts cannot drift.

## 1. Conventions

| Topic | Rule |
|-------|------|
| Auth | session cookie; unsafe methods also require `X-CSRF-Token` |
| IDs | UUID strings; human references (`claim_reference`) accepted only on search |
| Time | RFC 3339 UTC |
| Money | `{"amount": "4500.00", "currency": "USD"}` — amount is a **string** decimal |
| Pagination (lists) | `?page=1&page_size=25` (max 100) → `{"items": [...], "page": 1, "page_size": 25, "total": 312}` |
| Pagination (append-only streams: audit, events) | `?cursor=<opaque>&limit=100` → `{"items": [...], "next_cursor": "..."}` |
| Sorting / filtering | `?sort=-created_at,priority`; filters as explicit query params (allow-listed per endpoint) |
| Concurrency | mutable resources return `ETag: "<row_version>"`; PATCH requires `If-Match` → `412` on mismatch |
| Idempotency | `Idempotency-Key` header **required** on `POST /claims`, `/process`, review decisions, report generation; replay returns the stored response; same key with different body → `409` |
| Rate limits | `429` with `Retry-After` |
| Request id | `X-Request-ID` echoed / generated; included in errors and audit |

### Error format (RFC 9457 problem+json)

```json
{
  "type": "https://claimos.dev/problems/validation-error",
  "title": "Request validation failed",
  "status": 422,
  "code": "VALIDATION_ERROR",
  "detail": "incident_date must not be in the future",
  "request_id": "6a1f…",
  "errors": [{"loc": ["body", "incident_date"], "msg": "must not be in the future", "type": "value_error"}]
}
```

Codes: `UNAUTHENTICATED` 401, `FORBIDDEN` 403, `NOT_FOUND` 404 (also for cross-tenant), `CONFLICT` 409,
`INVALID_TRANSITION` 409, `PRECONDITION_FAILED` 412, `PAYLOAD_TOO_LARGE` 413, `UNSUPPORTED_MEDIA` 415,
`VALIDATION_ERROR` 422, `AUTHORITY_EXCEEDED` 403, `RATE_LIMITED` 429, `INTERNAL` 500, `DEPENDENCY_UNAVAILABLE` 503.

## 3. SSE stream contract

```
GET /api/v1/claims/{id}/processing/stream
Accept: text/event-stream
Last-Event-ID: 13

id: 14
event: node_completed
data: {"seq":14,"node":"POLICY_VERIFICATION","status":"succeeded","duration_ms":6120,"progress":0.55,...}

: heartbeat            (every 15 s)
```

Event types: `execution_started, node_started, node_completed, node_failed, retry, interrupt, resumed,
status_changed, execution_completed, execution_failed, execution_cancelled`. The stream closes after a terminal
event; clients reconnect with `Last-Event-ID`.
